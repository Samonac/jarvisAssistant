📖 Help & FAQ

J.A.R.V.I.S. (Just A Rather Very Intelligent System) is your personal AI assistant. Below is a guide to everything it can do and how to interact with it effectively.

⌨️ Keyboard Shortcuts

EnterSend message
Shift + EnterNew line (multiline input)
↑ / ↓Navigate through previously sent messages

💬 Chat & Conversation

Just type naturally. Jarvis understands context and maintains conversation history.

General chat What's the capital of France?
Follow-up And what's its population?
Time awareness What time is it?

📝 Mental Notes & Reminders

Jarvis can remember things for you and remind you at specific times. Notes can have due dates, commands to execute, and recurrence patterns.

Simple note Remember that my meeting is at 3pm tomorrow
Timed reminder Remind me in 30 minutes to check the oven
Recurring note Create a recurring note every 2 hours to drink water
Note with command Schedule a note for 9am daily to run "python health_check.py"
View notes What notes do you have?
Clear all Clear all notes
Acknowledge done — clears the last fired reminder

💡 Recurrence patterns: hourly, daily, weekly, every 5m, every 2h

⚙️ System Commands

Jarvis can execute shell commands on the host system. Dangerous commands are blocked by default.

Run a command Run the command "dir"
Natural language Show me the disk usage
Python script Run python test.py

🐍 Code Sandbox

Execute Python code directly in chat without creating files. Runs in a restricted environment with a 10-second timeout.

Direct code print(2 ** 10)
With instruction Run the following code: print("Hello World")
Multiline (Shift+Enter) import math
result = math.factorial(10)
print(f"10! = {result}")
Calculations Execute this: sum(range(1, 101))

💡 Available modules: math, json, datetime, random, re, collections, itertools, functools

💡 You can also use the interactive sandbox in the Settings page.

Search Search the web for "latest Python release"

💡 Action types: notify, run_command, briefing, smart_home, note, webhook

💡 Contextual Suggestions

Jarvis monitors your usage patterns and proactively suggests automations when it detects repetitive behavior.

What it detects Repetitive commands, time-based patterns, complex piped commands, frequent tool usage
OS history Reads your shell history (bash/zsh/PowerShell) for deeper pattern analysis
Suggestions Delivered as notifications — accept to create a workflow/script, or dismiss

💡 Suggestions appear after Jarvis has observed a pattern at least 3 times. You can trigger OS history ingestion via the API: POST /api/suggestions/ingest-history

🤖 Custom Assistants

Create your own AI assistants with custom personalities, system prompts, and inference parameters. Each assistant can be selected in the chat interface.

Manage Visit the Assistants page to create, edit, and delete assistants
Switch in chat Use the dropdown at the top of the chat to select an assistant
API: List GET /api/assistants
API: Create POST /api/assistants {"name": "Code Reviewer", "system_prompt": "...", "inference_params": {"max_tokens": 3000}}
API: Edit PUT /api/assistants/{id} {"inference_params": {"max_tokens": 4096, "temperature": 0.5}}
Default prompt GET /api/assistants/default-prompt — get the Jarvis system prompt as a starting template

💡 Each assistant has its own: system prompt, temperature, max_tokens, top_p, frequency_penalty, presence_penalty. Owners and admins can edit assistants. Shared assistants are visible to all users.

💡 For long-form content (stories, character sheets, reports), set max_tokens to 3000-4096 and frequency_penalty to 0.3-0.5 to avoid repetition.

⏱️ Cron Job Manager

Schedule recurring tasks with cron expressions or simple patterns. More powerful than notes-with-commands — supports full cron syntax, execution history, and output capture.

Simple patterns every 5m, every 1h, daily 08:00, hourly, weekly mon 09:00
Cron expressions */5 * * * * (every 5 min), 0 8 * * 1-5 (weekdays at 8am), 0 0 * * 0 (Sunday midnight)
API: Create job POST /api/cron {"name": "Health Check", "command": "python health.py", "schedule": "every 30m"}
API: List jobs GET /api/cron
API: Run manually POST /api/cron/{id}/run
API: View history GET /api/cron/{id}/history

💡 Jobs are evaluated every minute by the scheduler. Each execution's output and exit code are recorded in history.

📋 Log Analyzer

Monitor log files in real-time, detect error spikes, and receive alerts when things go wrong. Supports any text-based log file.

Add a watch POST /api/logs/watches {"file_path": "/var/log/syslog", "label": "System", "error_threshold": 5, "window_minutes": 5}
Tail a log GET /api/logs/tail?file=/var/log/syslog&lines=100
Search logs GET /api/logs/search?file=/var/log/syslog&pattern=ERROR.*timeout
Error summary GET /api/logs/errors?file=/var/log/syslog
View alerts GET /api/logs/alerts?unacknowledged=true

💡 Detected patterns: ERROR, CRITICAL, FATAL, Traceback, HTTP 4xx/5xx, OOM, ConnectionRefused, PermissionDenied, disk full. Alerts fire when errors exceed the threshold within the monitoring window.

🐳 Service & Docker Manager

Manage system services, Docker containers, and Git repositories — locally or on remote machines via SSH.

System Services (systemd/Windows)

List services GET /api/services or GET /api/services?host=myserver
Control service POST /api/services/nginx/restart — actions: start, stop, restart, enable, disable
Service status GET /api/services/nginx/status

Docker

List containers GET /api/docker/containers?all=true
Control container POST /api/docker/containers/myapp/restart — actions: start, stop, restart, pause, unpause
Container logs GET /api/docker/containers/myapp/logs?lines=100
Resource stats GET /api/docker/stats

Git

Repo status GET /api/git/status?repo=/path/to/repo
Pull latest POST /api/git/pull {"repo": ".", "host": "myserver"}
Commit log GET /api/git/log?repo=.&count=10

💡 All endpoints accept an optional host parameter to run on a remote machine via SSH. Service control actions (start/stop/restart) require admin permissions.

💾 Backup & Disaster Recovery

Automated backups of the Jarvis database, configuration, scripts, and plugins. Supports local and remote (SCP) destinations with integrity verification.

Run backup now POST /api/backups/run {"type": "full"} — types: full, db, config
View history GET /api/backups
Verify integrity POST /api/backups/{id}/verify — checks SHA256 checksum
Configure PUT /api/backups/config {"frequency": "daily", "time": "03:00", "remote_enabled": "true", "remote_host": "backup-server"}
Heartbeat GET /api/backups/heartbeat — public endpoint for external monitoring
DR Plan GET /api/backups/dr-plan — generates step-by-step recovery instructions

💡 Backups include: SQLite database, .env, requirements.txt, scripts/, plugins/. Configure include_uploads: true to also backup uploaded files.

💡 The heartbeat endpoint is public (no auth required) so external monitoring tools can check if Jarvis is alive. Status: healthy (<2min), warning (<10min), critical (>10min since last beat).

Disaster Recovery

The DR plan (GET /api/backups/dr-plan) provides:

  • Current backup status and RPO (Recovery Point Objective)
  • Step-by-step recovery instructions for a new instance
  • Recommendations for improving backup resilience
  • Instance health status based on heartbeat

🎯 Pro Tips

  • Multi-step reasoning: For complex tasks, Jarvis enters "agent mode" and chains multiple tools together automatically.
  • Conversation export: Click the ⬇️ button next to a session in the sidebar to export as XLSX.
  • Per-user isolation: Each user sees only their own conversations and notes. Admins see everything.
  • LLM failover: If one API key hits rate limits, Jarvis automatically switches to the next provider.
  • Auto-restart: Editing files in app/ triggers an automatic server restart.
  • Biometric login: Enroll your voice/face in Settings for hands-free authentication.
